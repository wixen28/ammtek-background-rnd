# RGB Mean background extraction

## Method

Per-pixel mean over frames sampled approximately evenly across the video.

The sampling interval is derived from the video frame count and requested
target frame count. Frames are processed in a streaming pass using the
shared sampling utility.

## Parameters

- `use_all_frames` (default true) — process every frame of the video.
- `target_frames` — approximate number of frames used when
  `use_all_frames` is false; sampled evenly across the whole video.
- `resize` — optional output resolution used during processing.

## Expected behavior

- Moving objects may remain visible as semi-transparent ghosting.
- Objects that stay in one place for a significant part of the video can
  strongly affect the resulting background.
- Increasing the number of sampled frames may reduce the influence of
  briefly visible objects, but also increases processing time.
- This experiment serves as the baseline for RGB Median and other methods.

## Diagnostics

- **Pixel timeline** (`GET /api/experiments/pixel-timeline?x=&y=`, section on
  the RGB Mean page): plots the R/G/B values of one pixel across every frame
  of the video. Used to inspect how foreground passes disturb a pixel before
  designing outlier rejection. No sampling; purely observational.
